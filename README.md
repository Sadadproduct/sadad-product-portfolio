# SADAD Executive Product Presentation — V2

Executive-level React/Vite presentation for Product Management at SADAD.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this folder as a Vite/React project. Vercel detects the framework and builds it with `npm run build`.
